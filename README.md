# massar-clone

Massar Clone is a school management system that lets students, teachers, and parents track grades, attendance, schedules, and exam results. It offers real-time updates, easy communication, and a user-friendly interface for managing all academic activities in one place.

## Features

- **Student Dashboard**: View grades, attendance, schedules, and exam results.  
- **Teacher Dashboard**: Record grades, monitor student performance, and manage class activities.  
- **Parent Dashboard**: Track your child's progress and communicate with teachers.  
- **Real-time Updates**: All changes are updated instantly for students, teachers, and parents.  
- **Notifications**: Get alerts for exams, assignments, or announcements.  
- **Secure Login**: Role-based access for students, teachers, and parents.  
- **Class Management**: Create and manage classes, subjects, and student lists.
